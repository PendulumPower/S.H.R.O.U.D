# S.H.R.O.U.D
A multiplayer horror game being developed by a team of 3 people.<br>
You are a member of S.H.R.O.U.D, the Special Hazard Recovery and Operations for Unknown Deviants.<br>
Whenever there is a report of a potential deviant, S.H.R.O.U.D is dispatched to identify and contain it.<br>
The risk is high, but the pay is worth it. Good luck, don't die.
